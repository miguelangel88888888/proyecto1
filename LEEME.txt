TIENDA - API REST DE PRODUCTOS

Requisitos:
- JDK 17
- MariaDB en ejecucion

Configuracion:
1. Ejecuta crear_base_de_datos.sql en MariaDB.
2. Configura las variables de entorno de conexion si tu instalacion no usa
   root sin contrasena:
   DB_URL=jdbc:mariadb://localhost:3306/tienda
   DB_USERNAME=tu_usuario
   DB_PASSWORD=tu_contrasena
3. Inicia la aplicacion desde esta carpeta:
   .\mvnw.cmd spring-boot:run

La tabla producto se crea o actualiza automaticamente mediante JPA.
La API escucha en http://localhost:8080 y expone:
- GET    /api/productos
- GET    /api/productos/{id}
- POST   /api/productos
- PUT    /api/productos/{id}
- DELETE /api/productos/{id}

Ejemplo de cuerpo JSON:
{
  "nombre": "Camiseta",
  "descripcion": "Algodon talla M",
  "precio": 45000,
  "stock": 20
}

Para ejecutar las pruebas:
.\mvnw.cmd test

Las pruebas usan una base H2 temporal; no requieren una instancia de MariaDB.
La coleccion de Postman esta en tienda-postman.json.
